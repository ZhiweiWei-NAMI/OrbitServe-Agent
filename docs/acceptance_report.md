## 6. 复现与证据保存

依赖固定于 requirements-lock.txt。Linux/Python3.11+、unshare 和 bubblewrap 是必要前提；安装步骤见 README。无后台服务依赖。

```bash
orbitserve prepare-data --data-root "$ORBITSERVE_DATA_ROOT"
orbitserve nodes --work-dir "$ORBITSERVE_RUN_ROOT/node-check"
orbitserve run --data-root "$ORBITSERVE_DATA_ROOT" --run-root "$ORBITSERVE_RUN_ROOT" --case lake_mead
orbitserve accept --data-root "$ORBITSERVE_DATA_ROOT" --run-root "$ORBITSERVE_RUN_ROOT"
```

每次运行记录代码/配置/输入哈希、依赖、时钟、实际工具与资源事件、传输和独立验收，并生成 summary.md。GitHub 仅含非数据代码、配置、说明和小型摘要。完整日志、manifests 和真实派生产品另外打包交付，避免临时环境重置后只剩 PASS 摘要；原始影像、参考答案、密钥和环境不进入该证据包或源码 ZIP。原始标准输入由固定下载脚本重新获取。已验证的 `OrbitServe-Agent-evidence-20261017.zip` 含 4,010 项、333,888,166 压缩字节；每项 SHA-256 均读回核验。归档内将原路径前缀 `/workspace/shared/` 对应到 `shared/`，完整清单记录逐文件映射和哈希；小型索引见 `evidence/evidence_bundle_summary.json`。

## 7. 未接入能力与模拟边界

未实现/未验证：LLM 规划器、学习式 WM、MARL。三种模式均显式报 NotImplementedError，无静默规则替代。这些不是原始 V0 必验门槛。

接触窗口、轨道角色、资源容量和能耗为明确的 synthetic_contact_trace / 模型参数；单主机进程不等于在轨异构硬件。规划成本是保守串行估计，不是最优调度器。水域结果是固定 MNDWI 阈值产生的候选变化及计算一致性，不宣称洪涝识别精度或外部标签验证。
